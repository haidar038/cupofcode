Design System & License

Dokumentasi pedoman visual (UI Tokens) Cup of Code sekaligus panduan hukum lisensi untuk semua aset open-source yang didistribusikan di platform ini.

Lisensi & Hak Cipta

Seluruh aset kode (Boilerplate, UI Kit HTML/Tailwind) dirilis di bawah MIT License. Sementara aset desain (Figma, Vektor) menggunakan CC BY 4.0. Intinya, kami membebaskan kamu untuk berkreasi.

Bebas Dilakukan

  • Pakai untuk proyek komersial (Klien/SaaS).
  • Modifikasi kode dan desain sebebasnya.
  • Pakai untuk media pembelajaran.

Dilarang Keras

  • Menjual ulang aset mentah di marketplace (Envato, UI8, dll).
  • Mengklaim sebagai pembuat asli tanpa modifikasi.

Palet Warna (Colors)

Sistem warna Cup of Code sangat minimalis. Memadukan warna gelap pekat sebagai fondasi elegan, dan kuning emas sebagai warna aksi (call-to-action).

Tipografi

Kami menggunakan dua font family: Cal Sans sebagai font display untuk judul, dan Google Sans Flex sebagai font body. Kombinasi ini dipilih karena keterbacaan (legibility) yang tinggi pada ukuran kecil dan karakter modern yang tegas pada ukuran besar.
